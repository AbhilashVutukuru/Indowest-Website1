## How does an AI agent work?
An agent works in five steps:
1. Understand — reads the request and its context
2. Plan — breaks the goal into steps
3. Act — uses your tools and systems
4. Check — asks a human when it matters
5. Improve — every run is logged and measured, so quality and cost keep getting better
